# Dandovdub Residoo

## How do I install these formulae?

`brew install dandovdub/residoo/<formula>`

Or `brew tap dandovdub/residoo` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dandovdub/residoo"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
